# 咨询回复规则

1. 首次回复 5 分钟内，主动提供案例演示
2. 先问场景（内部查阅/对外客服、本地/云端），再报价
3. 不直接发联系方式（平台会屏蔽），引导平台内沟通
4. 不承诺 100% 无错误，承诺大幅降低幻觉 + 可溯源
5. 成交前发需求确认清单，文字锁定交付边界

# 7天运营计划

## 每日
- 09:00 登录 + 擦亮商品
- 15:00 回复所有未读消息
- 20:00 查看同行新上架，优化描述

## 每周
- 更新 1-2 条商品（不同方向）
- 发布 3-5 个作品展示（截图/GitHub链接）
- 回复所有评价（引导复购）

## 避坑
- 不发外部联系方式（会被屏蔽）
- 第一单不高价（建立信用优先）
- 客户问能否做某功能，先确认需求再报价
