# 多渠道矩阵获客方案

## 一、三渠道策略

### B站

- 平台特征：长视频、技术深度内容、年轻用户
- 发布频率：每周2-3条
- 引流方式：视频简介留公众号/私信获取工具包
- 变现路径：视频引流 → 私域转化 → 接单
- 内容方向：
  - 【手把手】30分钟搭建自己的AI智能体
  - 我用AI自动写周报，老板以为我开挂了
  - AI接单3个月真实经验分享
  - 普通人如何用AI开发副业赚钱

### 小红书

- 平台特征：图文、种草、决策力强
- 发布频率：每天1条
- 引流方式：评论区引导、主页挂联系方式
- 变现路径：种草 → 专业形象 → 咨询 → 接单
- 内容方向：
  - 打工人必备的5个AI工具
  - AI做PPT有多离谱？我试了试
  - 从0开始做AI副业，我做了什么
  - 用AI一天做了10篇小红书文案

### 私域

- 平台特征：微信好友/社群/朋友圈，信任沉淀
- 发布频率：每天1-2条
- 引流方式：朋友圈留钩子（工具包/资料）
- 变现路径：信任建立 → 需求挖掘 → 方案定制 → 成交
- 内容方向：
  - 朋友圈每天1-2条案例/干货
  - 微信群分享AI工具使用技巧
  - 公众号发深度技术文章
  - 私聊维护核心客户
