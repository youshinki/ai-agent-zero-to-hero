# 项目分级与报价体系手册

## 一、四级项目分级

### L1 轻量基础版（参考价 ¥800）
- 适用：个人小需求、简单知识库体验
- 需求：基础RAG系统、文档批量入库、操作手册、7天BUG修复
- 工时：0.5-1个工作日
- 交付：基础RAG系统、文档批量入库、操作手册、7天BUG修复
- 付款：一次性或 50%+50%

### L2 商用标准版（参考价 ¥1200）
- 适用：小微企业内部知识库、员工资料查询、基础客服问答
- 需求：全格式文档解析、文本清洗、重排序检索、Token压缩、成本优化模块、少量界面微调、无复杂权限系统
- 工时：1-3个工作日
- 交付：全套商用源码、知识库全套能力、交付清单、完整文档、7天BUG修复
- 付款：50% 预付 + 50% 验收

### L3 深度定制版（参考价 ¥2500）
- 适用：商家多角色使用、企业多部门知识库
- 需求：多用户权限管理、独立账号、对接第三方系统（企微/飞书）、定制前端页面、专属业务逻辑开发、需要修改底层代码
- 工时：3-8个工作日
- 交付：定制开发完整系统、源码、部署文档、测试报告、15天BUG维护
- 付款：50% 预付 + 50% 验收

### L4 大型企业项目（参考价 ¥6000）
- 适用：中大型企业、多知识库隔离、完整后台管理
- 需求：多租户隔离、日志审计、高并发优化、对接企业业务系统、持续迭代开发、可配套月度运维
- 工时：8个工作日以上（分阶段）
- 交付：分阶段交付、完整工程文档、测试用例、上线部署、专属运维方案
- 付款：按里程碑分阶段收款

## 二、5维评估定级

- **文档规模与类型**：低=少量txt/md｜中=数十份常见格式｜高=大量扫描件/PDF图片/表格
- **定制开发需求**：低=纯使用现成成品｜中=少量界面微调｜高=新功能/改底层/定制UI
- **第三方对接需求**：低=无｜中=简单API｜高=企微/飞书/小程序/多系统
- **部署环境要求**：低=本地单机｜中=云服务器｜高=高可用/高并发/私有化集群
- **售后与运维要求**：低=7天BUG修复｜中=15天维护｜高=长期驻场/持续迭代

## 三、增值项

- 大批量扫描文档OCR解析：按文档数量计价
- 服务器部署、环境搭建：300元起
- 月度运维托管服务：500元/月起
- 新增独立功能模块：按预估工时报价

## 四、需求变更规则

- 开发前锁定交付需求清单
- 原有需求范围内BUG修复：免费（含在售后内）
- 新增功能/修改原有逻辑：需求变更，重新评估工时单独报价
- 无补充约定的新增需求，乙方有权拒绝开发

## 五、报价话术

### 客户嫌贵
咱们这个属于{tier}，交付的不是简单Demo，包含文档清洗、RAG重排、溯源引用、API成本优化全套商用能力，附带完整源码和交付文档。后期资料增量更新、长期使用稳定，避免廉价Demo的幻觉和崩溃问题。

### 客户预算有限
如果预算有限，可以降级到 L1 基础版，减少部分定制功能来降低预算，而不是在同等项目上直接砍价。

### 需求变更
本次报价对应的是咱们确认好的需求清单。如果后续新增功能，我这边评估工时，给您单独报一个新增项目的价格，这样项目周期可控，不会影响原定交付进度。


## 六、报价避坑

- 大单分阶段收款（预付50%，验收结清尾款）
- 不口头评估工时，需求/范围/报价全部文字确认
- 不为接单低估工作量
- 区分BUG修复与新增功能
- 不同渠道统一分级报价
