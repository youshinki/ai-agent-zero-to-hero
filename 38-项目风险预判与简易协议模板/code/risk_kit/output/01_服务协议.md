# AI知识库/Agent定制项目服务协议

甲方（委托方/客户）：XX科技有限公司
乙方（服务提供方/开发者）：开发者
签订日期：2026年10月19日

甲乙双方经友好协商，就AI私有知识库系统开发服务达成如下约定：

## 1、项目需求与交付范围

1.1 项目类型：☐L1轻量基础版 ☑L2 商用标准版 ☐L3深度定制版 ☐L4大型企业项目

1.2 本次交付功能清单：
   - 私有知识库搭建
   - 文档批量入库
   - 知识库问答（带溯源）
   - 商用干净输出
   - 使用手册 + 交付清单

1.3 本次交付**不含**：
   - 多用户权限管理
   - 第三方系统对接
   - 长期运维托管

1.4 交付物：源码、操作使用手册、项目交付清单。

1.5 交付周期：乙方收到预付款，且甲方提供全部所需文档素材后 3 个工作日完成交付。
    甲方素材延迟提供，交付时间自动顺延。

## 2、项目费用与付款节点

2.1 项目总费用：人民币 1200 元。

2.2 付款方式：预付款 50%，金额 600 元；
    项目开发完成、甲方验收通过后支付尾款 50%，金额 600 元。

2.3 项目执行过程中新增需求，双方另行评估工时与费用，签署补充约定后乙方才开始开发。
    无补充约定的新增需求，乙方有权拒绝开发。

## 3、素材、环境与API费用约定

3.1 项目所需文档、资料文件由甲方提供，甲方保证资料合法、不侵犯第三方版权。

3.2 甲方自行准备部署硬件、服务器环境、大模型API密钥及API调用费用，API消耗由甲方承担。

3.3 乙方保证交付代码在约定测试环境可正常运行；甲方本地特殊环境适配不属默认交付范围，如需适配另行报价。

## 4、验收标准

4.1 乙方完成开发后提供演示版本供甲方验收，验收周期为 3 个工作日。
    甲方在验收期内提出功能性BUG，乙方免费修复。

4.2 验收判定：系统实现协议1.2条约定全部功能，能够正常导入指定文档、
    完成问答检索、支持溯源，即为验收通过。

4.3 AI问答依托甲方提供文档内容作答，无法做到100%无偏差，乙方不承诺绝对零幻觉。
    甲方不能以主观层面不满意回答内容，判定项目不合格。

## 5、售后约定

5.1 免费售后周期：交付完成后 7 天，仅针对约定范围内功能BUG修复。

5.2 免费售后不包含：新增功能开发、环境迁移、API故障排查、甲方业务逻辑修改、
    人为误操作导致的系统问题。以上需求可单独付费。

## 6、知识产权与保密

6.1 乙方交付项目源码，甲方获得项目使用权；乙方底层基础框架知识产权归乙方所有。

6.2 双方对项目沟通资料、甲方业务文档信息保密，不得泄露给第三方。
