- APP_ENV=development：详细日志、暴露报错、便于调试

## 四、友好提示
- loading：正在加载资料，请稍候...
- thinking：正在思考并检索知识库...
- success：回答完成
- empty：暂未查询到相关内容，请换个问法或补充资料。
- error：系统繁忙，请稍后重试。
