# 企业私有知识库 · 官方使用手册

## 1. 系统介绍

本系统为企业私有化智能问答知识库，基于企业内部私有文档、规章制度、
产品资料、流程文件搭建，可实现员工自助问答、客户咨询答疑、新人培训辅助。
全程本地私有化存储，资料不泄露、不上传。

## 2. 基础使用方式

- 支持业务流程、产品参数、规章制度、售后标准等资料类提问
- 系统自动基于私有资料精准作答；无资料会如实提示，杜绝幻觉编造
- 输出内容经过商用排版，整洁清晰、重点明确

## 3. 资料更新方式

1. 将新增文档放入 `knowledge_base/data/` 目录
2. 执行批量增量入库（或调用 `/api/kb/batch_import` 接口）
3. 系统自动解析、清洗、去重、更新，无需重构系统

## 4. 系统优势

- **私有化部署**：企业资料百分百本地存储，安全可控
- **低成本运行**：自带缓存节流、智能模型路由，极低 API 开销
- **稳定可靠**：全局异常兜底，无崩溃、无报错、无乱输出

## 5. 常见问题

| 问题 | 处理方式 |
|------|----------|
| 提问返回"知识库暂无相关内容" | 确认资料已入库，或换一种问法 |
| 资料更新后未生效 | 重新执行批量增量入库 |
| 系统无响应 | 检查服务是否运行、端口是否占用 |
| 输出内容被拦截 | 涉及敏感信息，属正常隐私防护 |
