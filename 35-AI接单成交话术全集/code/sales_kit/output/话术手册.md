# AI接单成交话术手册

> 沟通固定顺序：展示案例 → 调研需求 → 评估项目 → 给出报价 → 确认清单


## 一、六阶段标准话术

### 阶段1 初次接待

**客户**：你好，请问AI知识库怎么做？

**回复**：您好，我们可以搭建私有RAG智能知识库，支持文档批量导入、智能问答、答案溯源。我这边有现成成品演示，您可以先看下效果。简单问两个问题确认下场景：您主要是用来员工内部查阅资料，还是对外客服答疑？需要部署在本地还是云端？

**要点**：快速回应 / 主动抛出案例 / 引导客户描述场景 / 掌握对话主动权

### 阶段2 需求深挖

**客户**：（客户描述了场景）

**回复**：好的，为了给您准确方案，再确认几个问题：
1. 需要导入的文档是什么格式，大概多少份？
2. 有没有特殊定制功能，比如权限管理、多用户登录？
3. 对响应速度、资料隐私是否有特殊要求？
4. 项目预计什么时候需要交付？

**要点**：判断项目大小 / 匹配套餐 / 为报价做准备

### 阶段3 异议应对

**客户**：别人才300块，你怎么贵这么多？

**回复**：低价大多只提供简单网页Demo，缺少文档清洗、溯源、成本优化、异常容错这些商用能力，后期容易出现幻觉、不稳定，而且不含完整源码和售后。我们交付的是可长期商用的完整系统，附带全套交付文档和BUG修复售后，一分钱对应一套完整交付标准。

**要点**：强调商用能力差异 / 强调源码与售后 / 不贬低同行，讲清价值

### 阶段4 报价谈判

**客户**：那你们多少钱？

**回复**：结合您说的场景，推荐标准版，费用1200元。包含：知识库搭建、文档批量入库、全套源码、操作手册、7天BUG修复。交付周期3-5天。您确认需求无误，我们就可以开始安排。

**要点**：先讲包含项再报价 / 给出交付周期 / 推动确认

### 阶段5 成交确认

**客户**：行，那我下单了。

**回复**：好的，收款前和您确认本次项目约定：
1. 交付内容：私有知识库系统源码 + 批量入库工具 + 交付文档
2. 交付周期：收到款项后3-5个工作日
3. 本次包含功能：文档入库、语义检索、知识库问答、商用输出
4. 不在本次交付范围：多用户权限、第三方系统对接
5. 售后范围：交付后7天免费修复功能BUG；新增功能不在售后内，单独报价。
您回复确认后我们开始动工。

**要点**：文字锁定边界 / 明确交付内容 / 明确售后范围

### 阶段6 成交后沟通

**客户**：（已付款）

**回复**：收到款项！我整理好需求清单，咱们按约定开发。过程中我会同步进度，交付时给您完整源码和操作教程，有问题随时沟通。

**要点**：及时响应 / 同步进度 / 建立信任


## 二、高频异议应对

### 比价
**客户**：别人才300块，你怎么贵这么多？

**回复**：低价大多是简单Demo，缺少清洗、溯源、成本优化、异常容错等商用能力，且不含完整源码和售后。我们交付可长期商用的完整系统 + 全套文档 + BUG修复售后。

### 免费试用
**客户**：能不能先试用，满意再付款？

**回复**：可以给您看成品演示视频，直观看到问答效果。但无法免费搭建专属知识库试用，因为文档解析、切片、入库需要完整开发工时。下单后按约定开发，交付后7天内功能性BUG免费修复。

### 资料泄露
**客户**：资料会不会泄露？

**回复**：整套系统支持本地私有化部署，文档全部保存在您自己的设备，不会上传第三方公共知识库；检索内容仅在本地处理，从底层规避资料外泄风险。

### 无限加需求
**客户**：我还想再加几个功能……

**回复**：理解您想完善功能。我们可以先把当前确定需求整理成清单，作为本次交付范围；新增功能单独评估工时和报价，这样项目边界清晰、交付周期可控。


## 三、沟通红线

1. 不承诺100%不出现任何问答错误，可承诺大幅降低幻觉、支持溯源核验

2. 不口头承诺额外功能，新增需求必须重新评估报价

3. 不与客户争论技术好坏，用案例演示代替争辩

4. 不承诺无限期免费维护，提前界定售后时间边界
