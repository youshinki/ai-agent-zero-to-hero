# AI Agent 从入门到实战（AI Agent Zero to Hero）

一套覆盖 **AI Agent 原理、实战、商业化与生产级工程** 的 75 篇连载教程开源仓库。内容源自同名头条连载与飞书知识库，按主题整理为 5 大模块，每篇独立成章：正文（README.md）、示例代码（code/）、配图（images/）。

## 模块总目录


### 模块一：AI Agent 入门与实战基础

从零认识 AI Agent：核心架构、思维链、记忆、工具调用、开发框架，到手写 Agent、RAG 知识库、多智能体协作等实战项目。

### 模块二：商业化改造与 AI 接单变现

把技术转化为收入：去除调试痕迹、商用封装、成本优化、获客、成交话术、报价体系与交付复盘。

### 模块三：企业级封装与交付工程

私有化部署、Windows 客户端打包、标准化接口封装与极致成本控制，打造可交付的企业级产品。

### 模块四：六大变现赛道详解

企业私有 RAG、自媒体内容、电商 AI 顾问、个人专属助理、行业答疑、办公自动化六大赛道拆解。

### 模块五：Agent 高级工程实战

架构总览、ReAct、Function Calling、Prompt Chain、评估、部署、安全、多租户、可观测性等生产级工程能力。

## 学习路径

- **零基础入门**：先读模块一（01-28），掌握 Agent 是什么、核心组件与第一个实战项目。
- **想靠 AI 接单变现**：在入门后直接进入模块二（29-40）与模块三（41-45），了解商业化改造与交付。
- **选定赛道**：模块四（46-51）拆解六大变现赛道，挑一个深耕。
- **进阶生产级**：模块五（52-75）覆盖部署、安全、可观测性等企业级工程能力，适合系统补齐短板。

建议顺序：01 → 75 按篇号顺序阅读；也可按模块跳读。

## 每篇结构

- `README.md`：完整正文（保留原文标题层级、列表、表格、代码块）。
