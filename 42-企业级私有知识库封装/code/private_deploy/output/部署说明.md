# 企业私有化部署说明

## 本地单机版
- 适合：小微企业、律所、教育机构、工作室
- 客户一台电脑/服务器即可安装
- 内网IP访问
- 数据留在本地
- 不强制上传外部文档
- 环境：2核CPU / 8GB内存 / 50GB磁盘

## 内网主机版
- 适合：有内网服务器的企业
- 内网域名/IP访问
- 不开放高危端口
- 支持自定义端口
- 离线/弱网环境可运行基础功能
- 环境：4核CPU / 16GB内存 / 100GB磁盘；内网固定IP

## 企业标准版
- 适合：中大型企业、多部门
- 多用户权限
- 操作审计
- 日志留存
- 私有模型接入
- 数据备份与恢复
- 环境：8核CPU / 32GB内存 / 500GB磁盘；可选GPU

## 内网离线能力
- 模型地址可配置：支持改为客户本地私有模型地址（如 http://192.168.1.10:8001/v1）
- 不依赖外网：核心问答/检索不调用外网；模型若用本地部署则完全离线
- 端口可配置：PORT 环境变量可改，避免占用高危端口
- 内网IP访问：HOST=0.0.0.0，内网通过服务器IP访问
- 离线兜底：无外网时返回友好提示，不崩溃
