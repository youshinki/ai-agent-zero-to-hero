【产品知识库 · 智能办公助手】

一、产品定位
智能办公助手是一套面向中小企业的私有知识库问答系统，所有数据保存在企业内网，不出网。

二、核心功能
1. 文档入库：支持 txt / md / pdf / docx 格式，自动切片、向量化。
2. 语义检索：基于向量相似度召回最相关片段，Top3 返回。
3. 知识库问答：先检索后生成，答案严格基于私有资料。
4. 记忆与压缩：支持多轮对话与长期记忆压缩。

三、部署要求
- 服务器：2核CPU / 8GB内存 / 50GB磁盘
- 系统：Ubuntu 20.04+ / CentOS 7+
- 依赖：Python 3.10+，numpy
- 可选：Docker 部署

- 标准版：19800 元，支持 20 个用户
- 企业版：39800 元起，支持私有化定制
