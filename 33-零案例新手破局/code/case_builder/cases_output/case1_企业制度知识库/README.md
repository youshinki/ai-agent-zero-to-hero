# 小微企业制度知识库 · 案例说明

## 项目背景
所有小微企业、工作室、个体户通用

**痛点：**
- 员工制度、考勤、报销规则分散，新人反复问
- HR 每天重复回答相同问题，效率低
- 制度更新后，旧文档仍在流传，口径不一致

## 项目能力
- 私有化部署，企业资料不出内网
- 批量解析 Word/PDF/TXT 制度文件
- 精准问答：入职、考勤、报销、岗位职责
- 无资料如实提示，杜绝编造
- 商用干净输出，可直接给员工使用

## 项目价值
- HR 答疑工作量下降 80%
- 新人培训周期缩短一半
- 制度口径统一，减少争议

- 示例资料库（3份文档已入库）
- 使用手册 + 售后方案
- 演示问答记录（demo_qa.md）
